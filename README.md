# KOKAN-POS

An offline-first point of sale for neighbourhood shops and eateries.

## Responsive interface

The app adapts its checkout and navigation to phones, foldables, tablets, and desktop displays. Mobile layouts account for iOS safe areas, support landscape use, and provide larger touch controls. Product and sales data remain stored locally first and sync when a connection is available. Cashiers can also park and resume multiple checkout tickets on the same device, including while offline.
